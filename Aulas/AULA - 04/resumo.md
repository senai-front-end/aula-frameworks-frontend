## Consumindo APIs no Front-end

* **API:** permite que diferentes sistemas se comuniquem.
* **HTTP:** protocolo usado para comunicação entre cliente e servidor.
* **Endpoint:** URL usada para acessar um recurso da API.
* **JSON:** formato usado para enviar e receber dados. 

## Métodos HTTP

* **GET** → buscar dados
* **POST** → criar dados
* **PUT/PATCH** → atualizar dados
* **DELETE** → excluir dados 

## Como funciona

**Front-end -> Requisição HTTP -> Backend -> Banco/API -> Resposta JSON -> Front-end**

O front-end envia uma requisição, o servidor processa e devolve os dados para serem mostrados na tela. 

## Backend e Express

* **Backend:** processa requisições, dados e regras de negócio.
* **Web Service:** permite comunicação entre sistemas pela web.
* **Express.js:** framework do Node.js usado para criar servidores e APIs.
* **CORS:** controla o acesso entre diferentes domínios.
